# Chronaxis 0.1.0.dev2

[English](release-notes-0.1.0.dev2.en.md)

本版扩展配置校验、表达式与统计计算，增加高性能积分器，并同步中英文手册和随包 AI 指南。它仍属于开发预览版，运行环境为 Windows、Python 3.12。

安装或升级：

```powershell
python -m pip install --upgrade "chronaxis==0.1.0.dev2"
python -m chronaxis guide
```

## 相比 0.1.0.dev1 的变化

| 功能 | 本版行为 |
|---|---|
| 配置诊断 | 一次返回多个可独立定位的配置错误，给出字段位置；依赖错误字段的后续检查仍可能需要先修正前置错误。 |
| 结果发布 | 可以重复使用输出目录；同次输出采用统一时间后缀，不覆盖已有文件，完成清单最后发布。 |
| 单位与表达式 | 分析配置使用版本 4，支持兼容单位自动换算、带单位常量、条件分支、数值与位运算、一维标定查表。 |
| 统计与时序变换 | 增加计数、方差、标准差、均方根、分位数和中位数，以及结果聚合、滚动统计和变化率。 |
| 自定义分析算子 | 宿主 Python 程序可显式注册表达式、统计和时序算子，配置按注册名称使用。 |
| 高性能积分器 | 使用独立的 `fast validate/explain/run` 和 `fast batch` 入口，对独立 ASC/BLF 文件中的同帧公式逐报文累计；批量任务支持按文件并行。它有明确的支持范围，不会自动替换通用分析。 |
| 使用资料 | 完善功能说明、配置示例及实际结果解释，提供中英文手册和可直接阅读的 AI 指南；教学结果在各分发形式中保留原始字节，并核对摘要。 |

高性能积分器直接累计每条匹配报文的表达式结果。由功率求能量时，表达式需要包含相应时间因子；如果输入已经是每条报文的能量贡献，则直接累计。性能取决于任务和输入，不能把该入口的测量结果推广到所有分析。

已完成真实数据数值和功能核对，但部分耗时、内存目标仍未达到。请按任务和可用资源选择高性能积分器；本次发布不表示全部性能目标已通过。

## 从旧版升级

**本版只接受整数 `config_version: 4`。** 版本 3 分析配置、旧 INI 专用导入入口及其映射配置已移除。独立批量清单仍使用 `batch_version: 1`；它与分析配置的版本号分别管理。

请参照当前示例核对旧分析配置，不能只把 `3` 改成 `4` 就认为结果含义不变：

1. 核对信号的输入单位、目标单位和换算系数。`conversion.scale` 与 `conversion.offset` 都未填写时，程序按已登记的兼容单位自动换算；显式填写任一个系数时会校验完整换算，不再额外叠加一次自动换算。
2. 核对表达式中的常量单位、比较与计算输出单位，按当前字段规则处理报错。先用已知输入和结果运行小例，再处理实际日志。
3. 旧 INI 任务需要按当前分析配置重新表达。YAML／JSON 格式转换命令只转换文件格式，不会自动迁移配置版本或旧业务含义。
4. 若其他程序读取输出文件，不要依赖固定文件名；使用本次返回的运行清单定位带时间后缀的结果。

字段和示例见[信号绑定](../Current/signals.md)、[表达式](../Current/expressions.md)、[统计与积分](../Current/calculations.md)、[时序变换](../Current/temporal-transforms.md)、[自定义分析算子](../Current/host-extensions.md)及[高性能积分器](../Current/fast-energy.md)。
