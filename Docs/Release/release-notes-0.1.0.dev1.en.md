# Chronaxis 0.1.0.dev1

[简体中文](release-notes-0.1.0.dev1.md)

This release corrects the distribution documentation and its entry points. The PyPI Documentation link opens the [online HTML manual](https://liuyaoze98.github.io/Chronaxis/); the [English manual](https://liuyaoze98.github.io/Chronaxis/en/) is available alongside it. Both READMEs, installation instructions, bundled AI guides, and the software version in results now identify 0.1.0.dev1.

Install with `python -m pip install "chronaxis==0.1.0.dev1"`. The supported environment remains Windows with Python 3.12. Computation algorithms, configuration semantics, and runtime dependencies are unchanged from 0.1.0.dev0.

Version 0.1.0.dev0 remains available. Each GitHub Release provides its offline HTML manual; the online entry serves the current release manual.

Maintainer: liuyaoze, work@liuyaoze.com.
