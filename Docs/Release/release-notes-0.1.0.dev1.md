# Chronaxis 0.1.0.dev1

[English](release-notes-0.1.0.dev1.en.md)

本次修正发布资料与文档入口。PyPI 的 Documentation 链接直接打开[在线 HTML 手册](https://liuyaoze98.github.io/Chronaxis/)，英文手册位于[English](https://liuyaoze98.github.io/Chronaxis/en/)。中英文 README、安装说明、随包 AI 指南和结果中的软件版本号同步为 0.1.0.dev1。

安装：`python -m pip install "chronaxis==0.1.0.dev1"`。运行环境仍为 Windows、Python 3.12；计算算法、配置语义和运行依赖与 0.1.0.dev0 相同。

此前发布的 0.1.0.dev0 保留。各版本的离线 HTML 手册可从对应 GitHub Release 下载；在线入口提供当前发布版手册。
