# 支持范围与限制

本页帮助判断当前版本能否处理你的输入和分析任务。配置版本固定为整数3；手写使用YAML，程序交换也可用JSON。软件0.1.0.dev1为开发预览版，支持安装发行wheel或从公开源码构建，见[安装说明](installation.md)。

| 能力 | 当前支持范围 |
|---|---|
| 输入 | 内存记录、已解码信号CSV、配DBC的BLF/ASC/原始CAN CSV；文件数量、通道及格式限制见[来源指南](inputs.md)。 |
| 分析 | 表达式、持续条件、边沿、迟滞、去抖、起止活动、窗口变化、请求响应配对、事件窗口、统计与积分、逐消息累计。 |
| 执行 | Python API与CLI，reference/numpy两种计算实现，独立批量任务，内存/暂存预算管理。 |
| 输出 | CSV或JSONL摘要、运行清单、按需贡献/输入追溯、信号CSV与CAN报文导出。 |
| 配置工具 | 模板生成、YAML/JSON转换、独立配置导出、单层公共定义、字段来源查询、旧INI显式导入。 |
| 环境 | Python要求>=3.12且<3.13；实际验证环境为Windows/Python3.12。正式结果先完整写入临时目录并关闭文件，再把整个目录一次改名为目标目录；目标已存在则拒绝覆盖。该发布方式目前仅验收Windows，其他平台不能据声明推定可发布。详见[结果发布](results.md#result-publication)。 |

## 需要自行确认的条件

数据的时间同步依据、信号单位、方向、测量位置、有效期和业务阈值需要由使用者确认。加载配置不读取业务报文；省略信号dtype、unit、period或枚举choices时，程序可按对应规则从DBC补齐；仍须提供报文frame_id和信号signal，通道仅在唯一时可省略。标准/扩展帧和CAN/FD标志可自动确定，候选不唯一时须补填。具体条件见[信号绑定](signals.md)与[来源](inputs.md)。读取DBC仍无法证明业务输入内容正确；合成示例可核对计算方法，不能证明真实设备的业务结果。

部分导出路径仍限制metadata.device_label为home/work，见[输出限制](exports.md)。内存预算只覆盖受管理资源，不是整个Python进程的硬上限。多任务并行或NumPy实现不保证所有输入都加速，应基于实际任务测量。
