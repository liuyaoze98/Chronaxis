# chronaxis.execution

保存新执行层内部组件，公共入口由根包AnalysisRunner按需加载。

输入为已解码批次，历史组件输出有限单行重放；模块本身不读取旧来源。
run_session协调来源创建、同组归并和已实现算子，资源用量记录复用结果层。
本模块自身仅说明包职责，导入不读取来源、创建目录或保存运行状态。

这是模块参考。日常调用先查[公开API索引](../api.md)；下划线对象、嵌套函数和vendor实现供维护者查阅。签名来自固定源码，公开类构造签名经实际Python接口核对。
